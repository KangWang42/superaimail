# 使用指南

## 收件与阅读

添加邮箱后，后台会逐步索引近 60 天的邮件。首次同步的历史邮件默认已读，新邮件默认未读。邮箱列表可看到连接状态；首次同步期间应等待索引完成，不要反复添加同一个邮箱。

收件箱可切换全部、未读、待处理和有附件；下拉框可选择邮箱、分类、已发送、归档、稍后处理、回收站或全部邮件。普通搜索匹配主题、发件人和已保存正文。AI 开启后，可以输入“上周带附件的账单”再点击「AI 查找」。

点开邮件后可阅读正文、下载附件、添加星标、更改分类、归档或稍后处理。排版正文在「查看排版正文」中展开，远程图片默认关闭，以减少跟踪请求。正文中的外部链接会在浏览器打开，请按普通邮件的方式判断其真实性。

「全部已读」应用于当前筛选条件的所有分页，不只当前屏幕上显示的邮件。「归档」「删除」仅改变本应用状态，原邮箱不变；删除的邮件可以在回收站恢复。

## 发信

1. 点「写邮件」，选择发信邮箱，填写收件人、主题和纯文本正文。
2. 点击「预览发送」，核对实际收件人、抄送与正文。
3. 点击「确认发送」。预览令牌只可使用一次，15 分钟后失效。

回复从原邮件建立引用关系。AI 起草只产生草稿，你可以修改后再预览。发送失败时不要立即重复点击：先查看逐个收件人的结果，确认哪些已成功，再对失败对象重新撰写。

当前不支持发出附件或富文本编辑。已发邮件保存到本地「已发送」，不会自动上传到服务商的已发送文件夹。SMTP 显示成功但本地副本保存失败时，界面会说明，不会自动重发。

## 收集附件

适用于课程作业、报名材料、会议资料、评分表和项目文件。

1. 新建收集任务，选择收件邮箱，填写任务名与主题关键词。
2. 设定开始时间、可选截止时间与附件类型。关键词用逗号分隔。
3. 填写人员名单，每行一个姓名，可在后面加邮箱；不写名单时也可按提交信息识别姓名。
4. 选择保留原名、按模板命名或 AI 整理。模板支持 `{姓名}`、`{关键词}`、`{任务}`、`{原文件名}`、`{日期}`。
5. 保存后回扫已有邮件。任务页显示已提交、未提交与待确认。

同一人再次提交时保留历史版本，ZIP 可导出最新附件或包含历史。姓名与邮箱冲突时不会随意覆盖已确认的提交；在待确认列表指定提交人后，可以记住对应关系。

截止后仍会收集，晚交会标注。暂停任务会停止匹配；结束任务后可以重新开启。删除任务会删除本应用的任务记录与归档文件，原始邮件不变。

单个收集附件上限为 50 MiB，下载请求另有有界限制。压缩包仅归档，不自动解压或执行。

## 分类与规则

分类描述供 AI 判断；手动更改过的分类优先保留。规则用于确定的发件人或主题关键词，并为新邮件加标签，可选择正常提醒或静默。规则标签与 AI 分类是两个字段。

只有启用 AI 并成功产生关注程度后，「待处理」才能充分发挥作用；未分类邮件不会直接被当作低优先级丢弃。请定期查看全部收件箱。

## 数据、备份与迁移

数据目录主要包含：

```text
access.json      工作台密码哈希与会话签名材料
accounts.json    邮箱授权码、OAuth 令牌、代理与 AI 设置
ai.key           模型 API Key
mail.db          邮件索引、正文、任务与事件
files/           任务归档附件
```

退出浏览器会话不会停止后台；关闭后台进程才停止收件。默认索引保留 180 天，收集任务引用的邮件不按普通索引清理。需要长期保存的原邮件仍应由服务商邮箱或专门归档保存。

备份前停止后台，再完整复制数据目录。SQLite 正在运行时可能存在 `mail.db-wal`，不要只复制单个数据库文件。恢复时也先停止应用，用同一版本或更新版本读取完整目录。

访问密码丢失时，在后台设备运行 `python -m superaimail init --data 数据目录` 重新设置；旧会话随即失效。该操作不改变邮箱授权码。

## 常见问题

**邮箱提示登录失败。** 先确认使用客户端授权码，检查 IMAP 是否开启、企业管理员是否限制客户端，以及网络是否能从后台设备到达服务商。Outlook 优先使用 Microsoft OAuth。

**能收不能发。** 检查 SMTP 主机、端口和 TLS / STARTTLS。企业账号可能禁止 SMTP AUTH，需要管理员开启；OAuth 也不会绕过租户策略。

**电脑和手机状态不一致。** 两端独立后台的状态不会自动同步。改为连接同一服务即可共享；不应直接让两个进程同时读写共享盘上的 SQLite。

**关闭应用后没有新邮件。** 后台设备必须保持运行。手机后台还受系统限制，要求持续在线时使用服务器共享模式。

**为什么原邮箱的已读状态没变。** 本应用使用只读 IMAP，本地处理不会更改原邮箱。这也便于安全试用和与其他客户端同时使用。
